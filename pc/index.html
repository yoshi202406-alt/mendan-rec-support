面談録音 PC を入れる

iPhoneアプリ「面談録音」の録音を受け取り、報告書の下書きを作る、Windows用のソフトです。無料で入れられます。

ダウンロード（準備中）

いま公開の準備をしています。公開すると、このボタンからダウンロードできるようになります。

入れ方

  1. 上の「ダウンロード」を押します。
    事業所のPC（Windows）で、このページを開いて押してください。

    「一般的にダウンロードされていません」と出たら

    MendanPC-Setup….exe は一般的にダウンロードされていません。　1…

    2保存

    3詳細表示　4保持する

    ブラウザー（Microsoft Edge）の右上に出ます。ファイルの名前にマウスを合わせて「…」を押し、「保存」→「詳細表示」→「保持する」の順に押します。

  2. ダウンロードしたファイルを開きます。
    ブラウザーの右上の「ファイルを開く」を押すか、「ダウンロード」フォルダーの中の MendanPC-Setup をダブルクリックします。

    青い画面「Windows によって PC が保護されました」が出たら

    Windows によって PC が保護されました

    1詳細情報

    2実行　実行しない

    はじめは「実行」のボタンがありません。「詳細情報」を押すと出てくるので、「実行」を押します。

  3. 「インストール」を押します。
    押すのはこのボタン1つです。1分ほどで入れ終わり、「面談録音 PC」が自動で開きます。
  4. PCの画面にQRコードが出ます。
    はじめに「受け取れるようにする」のボタンが出たときは、それを押し、Windowsの確認には「はい」を押します。iPhoneからの録音を、このPCで受け取れるようにするためのものです。
  5. iPhoneでQRコードを読み取ります。
    iPhoneの「面談録音」で「QRコードを読み取る」を押し、PCの画面のQRコードを写します。これでiPhoneとPCがつながります。

つながったあとの準備（OpenAI のキーの登録など）は、PCの画面とiPhoneの画面に、次にやることが1つずつ出ます。

上の2つの確認は、公開して間もないソフトにWindowsが出すものです。このページのボタンからダウンロードしたファイルであれば、そのまま進めてください。

使えるPC

  • Windows 10 または Windows 11
  • Microsoft Excel が入っていること（報告書の様式に書き込むために使います）
  • iPhoneと同じWi-Fiにつながっていること

うまくいかないとき

iPhoneでQRコードを読み取っても、つながらない
iPhoneがPCと同じWi-Fiにつながっているかを確かめてください。モバイル通信や、来客用のWi-Fiではつながりません。iPhoneの「設定」で、「面談録音」の「ローカルネットワーク」がオンになっているかも確かめてください。

PCの画面にQRコードが出ていない
PCのデスクトップにある「面談録音 PC」を開いてください。前につないだことのあるPCでは、「設定」の「QRコードを表示」を押すと出ます。

PCの画面に「録音を受け取れません」と出ている
「受け取れるようにする」を押し、Windowsの確認には「はい」を押してください。
